# YouTube research handoff

Bu klasör Gemini'nin video/transkript erişiminden ürettiği yapılandırılmış araştırma notları içindir.

Önerilen dosya adı:
`YYYYMMDD-<video-id-or-slug>.md`

Her dosyada mümkünse:
- URL
- başlık / kanal / tarih
- erişim yöntemi
- transcript/caption türü
- zaman damgalı bölüm notları
- ana bulgular
- kısa kritik alıntılar
- belirsizlikler
- ilgili görev ID'si

Public repo olduğu için üçüncü taraf videoların tam uzun telifli transkriptlerini varsayılan olarak burada saklamayın.
