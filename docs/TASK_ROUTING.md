# Task routing

User goal → ChatGPT strategy (default) or single-lead fast path.

- Research / trend / red-team → Grok (`messages/chatgpt-to-grok.md` veya shared-inbox)
- Code / merge / Shopify admin-read → ChatGPT
- Video / multimodal → `messages/inbox-gemini.md` status queued
- Public page fetch → `messages/inbox-tinyfish.md` status queued
- Meta web opinion → `messages/paste-from-meta.md` veya inbox-meta
- Durable fact → `knowledge/lessons.md`
- Status → `state/now.json` only

Overflow: GrokBot → Grok → Gemini. Max 5 standing CORE tasks.
